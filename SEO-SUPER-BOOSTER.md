# SEO Super Booster — Destiny 2 Cheats (destiny2cheats.org)

Implementation playbook for this Astro template. Every item below is **enforced in CI** via `npm run build` (`verify-seo.mjs`, `verify-redirects.mjs`).

## 1. Single canonical host

- `SITE_URL` / `SITE_HOST` in `src/data/seo-booster.ts` (from `brand.url`) → `https://destiny2cheats.org` (apex, no `www`).
- `src/worker.ts` and `functions/_middleware.js` → **301** `www` → apex.
- Every HTML page: self-referencing `rel=canonical`, `hreflang=en`, `hreflang=x-default` on the same apex URL (or full locale set via `I18nHead`).

## 2. Page-level metadata discipline

- One `<h1>` per indexed page; unique `<title>` and `meta description` on key money pages (no duplicates).
- `og:title` / `og:description` match `<title>` / description exactly.
- `og:image` + `twitter:image` → `https://destiny2cheats.org/og/*.jpg` at **1200×630** (`og:image:width` / `height`).
- `rel=image_src` on all indexable pages.
- `robots`: `index, follow, max-image-preview:large, max-snippet:-1, max-video-preview:-1` (`ROBOTS_INDEX` in `seo-booster.ts`).
- No `meta keywords`, no `SearchAction`, no keyword-list JSON-LD.

## 3. Structured data graph

- Shared `@id` `https://destiny2cheats.org/#product` on home, `/d2-cheats/`, and reviews.
- `Organization` + `WebSite` on every page (`siteIdentityGraph()` in `Layout.astro`); `SITE_PURPOSE` states **Destiny 2 only**.
- `SITE_ABOUT`: exactly **6** `knowsAbout` terms.
- Product `FAQPage` only on `/faq/` (one graph). FAQ detail pages use `Question` only. Reviews index: all on-site `Review` nodes + `AggregateRating` 4.6.
- Forums index: `BreadcrumbList` (via layout breadcrumbs).

## 5. Media & thumbnails

- Optional raw gameplay PNGs in `assets/gameplay/` as `images_1.png` … `images_11.png`.
- Run `npm run prepare:media` → writes `public/images/destiny-2-*.webp` and `public/media/d2-screenshot-*.webp`.
- Self-hosted `/images/destiny-2-*`; hero uses `brand.heroImage` / `heroVideo`.
- `npm run generate:seo-assets` builds all `/og/*.jpg` from first-party screenshots (run after `prepare:media` or when `public/images` exists).
- Carousel alts: `src/data/media.ts` (`PRODUCT_PREVIEW_GALLERY`) — keep descriptions unique.

## 6. Sitemap

- `sitemap.xml` index + locale/image sitemaps (existing Astro routes).
- Image entries per brand `sitemap.images` in `src/data/brand.ts`.
- `<?xml-stylesheet href="/sitemap.css"?>` on urlsets where configured.
- No duplicate hreflang in XML (HTML only).

## 7. Crawl rules

- `robots.txt`: `Sitemap: https://destiny2cheats.org/sitemap.xml`, `Allow: /sitemap.xml`, `Allow: /videos/`, explicit `Googlebot` (regenerated by `sync:brand`).
- `public/_routes.json` excludes `/sitemap.xml` and `/robots.txt` from Functions.

## 8. Keyword URL aliases (`public/_redirects`)

301 legacy and commercial paths to money pages — synced by `scripts/sync-en-redirects.mjs` and `functions/_middleware.js`:

- Long paths (`/destiny-2-cheats`, `/best-destiny-2-cheats`, …) → `/d2-cheats/`
- Legacy game paths (Fortnite, Warzone, Tarkov, …) → D2 pillars
- Retired sitemap filenames → `/sitemap.xml`

## 9. Build commands

```bash
npm run prepare:media        # optional gameplay import
npm run generate:seo-assets
npm run build                # full pipeline + verification
```

## 10. External / off-page signals (site-controlled)

- **Social previews**: Money pages use first-party `/og/*.jpg` (1200×630) via `socialPreviewImageForPage()` — not hero WebPs.
- **E-E-A-T outbound**: Footer + EN home compact block link to Bungie, Bungie Help, BattlEye, Steam, and wiki references (`official-resources.ts`) with `rel="noopener noreferrer"`.
- **Organization.sameAs**: Optional `brand.sameAs` URLs in `src/data/brand.ts` → JSON-LD when non-empty.
- **Discovery files**: `npm run sync:brand` writes `public/llms.txt`, `public/security.txt`, and `public/.well-known/security.txt`; robots allows them.
- **Head hints**: `rel=help` → `/llms.txt`, `referrer` policy, `rel=sitemap` on every page.
- **CI**: `verify-seo.mjs` checks llms/security files, booster OG dimensions on home, authoritative footer links, and external `target=_blank` + `noopener`.

## 11. Rebrand checklist (new game)

1. Edit `src/data/brand.ts` (URL, name, keywords, plans) → `npm run sync:brand`
2. Edit `src/data/seo-booster.ts` (`SITE_PURPOSE`, `SEO_ROUTE_INTENTS`, `SITE_ABOUT` terms).
3. Update FAQs / reviews in `src/data/site.ts`.
4. Replace `public/images` and hero video.
5. Update `scripts/verify-seo.mjs` / middleware host strings if domain changes.
6. `npm run build` until verification passes.
